# Our Notes

共有するメモのようなアプリケーション。SPAで3つのページを切り替え可能なネイティブアプリのようなUIを持ちます。

## 機能

- 5つのページから構成されるSPA（ショッピング、マップ、カレンダー、単語帳、四字熟語クイズ）
- 単語帳ページでは英語・日本語・中国語の対応表を登録可能（アイコンタップで訳を表示/非表示、検索対応）
- 四字熟語クイズページでは絵文字を見て四字熟語を当てるゲーム（中日両方の解答表示、489問収録）
- 画面下に切り替えのUIがあるネイティブアプリのようなUI
- 右下に「＋」ボタンでメモを追加可能
- 「ペン」ボタンで編集モードに切り替え、メモの削除が可能

## 技術スタック

- フロントエンド: Vite + Vue 3 + TypeScript
- バックエンド: Hono
- デプロイ: Cloudflare Workers
- PWA対応
